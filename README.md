# AdminCmd
Плагин для сервера Mindustry (ultra optimized)

Отполирован код (2.8 кб / 30 строк), просто админ команды, сделать паузу или возобновить `/p` и сменить карту `/m Название_карты`  (`/m l` - список карт)

Протестировано на сервере с 1 ядром и 300 мб оперативки (боже, задонатьте мне пж), Потребляет ~1 кб ОЗУ на 20 карт.

Компилируйте сами, моментально компилируется: `gradle clean jar` или ждите обновления раз в месяц :(
